Заявки разобраны. Ответ — за вами

Утром во входящих сорок новых заявок. Кому-то груз нужен сегодня, кто-то пишет на казахском, кто-то жалуется вежливым вопросом. Помощник разбирает их до того, как менеджер откроет почту, и честно помечает то, в чём не уверен.

01—08

Что умеет помощник

01

Разбор каждой заявки

Категория, приоритет и черновик ответа на языке клиента. Рядом — дословные цитаты, на которых держится решение, и следующий шаг для менеджера.

  • категория
  • high · medium · low
  • черновик
  • следующий шаг
02

Своя модель, свой сервер

Открытая Qwen3 на llama.cpp. Без регистрации, ключей и интернета во время работы — данные клиентов не покидают сервер. Модель выбирается при запуске.

  • Qwen3-14B · GPU
  • Qwen3-8B · CPU
  • Ollama · LM Studio · vLLM
03

Три инструмента — и всё

Агент работает с заявками только через MCP: list_leads, get_lead, update_lead. Тот же сервер подключается к Claude Code одной строкой.

  • MCP stdio
  • единый формат ошибок
  • трейс вызовов
04

Код проверяет модель

Категорию и приоритет выводит код — из цитат, которые модель достала из заявки. Черновик с обещаниями и фактами не из заявки сервер не запишет. Спорное помечается uncertain с причиной.

  • цитаты-основания
  • защита от инъекций
  • uncertain
05

Запись, которая не теряет

Блокировка между процессами, атомарная замена файла, конфликт возвращается явно. Повторный запуск безопасен: обработанные заявки не перезаписываются.

  • file lock
  • atomic replace
  • идемпотентность
06

Рабочее место менеджера

Список с поиском и фильтрами, карточка заявки, «Принять / Исправить / Отклонить» с историей, очередь проверки, база знаний, роли и тёмная тема.

  • папки
  • история решений
  • база знаний
  • роли
07

Почта и Telegram

Заявки приходят из ящиков и ботов сотрудников — сколько угодно. Ответ уходит тем же каналом: письмом или через бота, с понятной причиной, если не ушёл.

  • IMAP / SMTP
  • Telegram-боты
  • ответ из карточки
08

Качество в цифрах

Набор из 18 примеров и разметка 15 реальных заявок. Каждый прогон оставляет трейс в runs/, а счётчики сводки сверяются с файлом.

  • evals synthetic
  • evals real
  • сводка = файл
