# Видео для лендинга

Положите ролики в эту папку под этими именами — лендинг подхватит их сам. Пока файла
нет, в рамке крутится анимированная заглушка с названием пункта.

| Файл | Где на странице | Что показать |
|---|---|---|
| `00-hero.mp4` | фон первого экрана (поверх WebGL, прозрачность 35%) | абстрактный поток заявок / данные, тёмный фон |
| `01-triage.mp4` | 01 · Разбор каждой заявки | заявка → категория, приоритет, черновик |
| `02-local-model.mp4` | 02 · Своя модель, свой сервер | локальный сервер, данные не уходят наружу |
| `03-mcp-tools.mp4` | 03 · Три инструмента — и всё | list_leads / get_lead / update_lead |
| `04-guardrails.mp4` | 04 · Код проверяет модель | цитаты-основания, отбракованный черновик |
| `05-reliability.mp4` | 05 · Запись, которая не теряет | блокировка, атомарная запись |
| `06-workspace.mp4` | 06 · Рабочее место менеджера | интерфейс: список, карточка, «Принять» |
| `07-channels.mp4` | 07 · Почта и Telegram | письма и боты сходятся в одну очередь |
| `08-quality.mp4` | 08 · Качество в цифрах | метрики, трейсы прогонов |

Рекомендации: MP4 (H.264), 16:10 или 16:9, 1600–1920 px по ширине, 6–12 с с бесшовной
петлёй, без звука (видео всегда без звука), до ~8 МБ на ролик. Тёмный фон смотрится
лучше всего — страница тёмная. Другое имя или формат — поменяйте атрибут `data-video`
в `index.html`.

## Что лежит сейчас

Все девять роликов сделаны (1600×1000, H.264, без звука, бесшовная петля). Интерфейс
снят в тёмной теме на демо-копии с вымышленными письмами. Ролики 02–05 — анимированные
сцены со строками из реального прогона Qwen3-14B (`evidence/local/14b-final2`), 00 —
абстрактная анимация потока заявок.

`certa-instrukciya.mp4` (3:14, со звуком и субтитрами) и постер `certa-instrukciya.jpg` —
полная видеоинструкция в блоке «Видеоинструкция» (`#video`).

Пересборка: скрипты в `../../video/` — `make_video.py` (полное видео), `clips.py` и
`scenes.html` (ролики). Нужны запущенная демо-копия приложения и демо-логин.
