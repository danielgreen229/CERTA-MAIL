# Диалоги с ИИ

| Файл | Что это |
|---|---|
| `development-session.zip` | Основная сессия разработки (Claude Code, Opus): этап 2 и доработки — рабочее место, почта и Telegram, отправка ответов, дизайн, обучение, документация. Внутри — разговор, транскрипты помощников (рефакторинг, UML-диаграммы) и метаданные |
| `stage1-development-session.zip` | Сессия этапа 1: MCP-сервер, агент на локальной модели, наборы оценки |
| `stage1-model-dialog-acceptance-run.jsonl` | Диалог агента с локальной моделью Qwen3 во время приёмочного прогона: запросы, вызовы MCP, ответы |
| `claude-code-demo-session.zip` | Демонстрация: Claude Code по `/process-leads` сам нашёл три MCP-инструмента проекта и обработал 14 заявок |

Личные данные и секреты заменены метками `<…-hidden>`: email, пароли сервера, DNS и почтового
ящика, адрес сервера, локальные пароли, имя и логин Telegram, имя компьютера. Перед публикацией
все файлы проверены поиском по этим значениям и по шаблону токена Telegram-бота.
