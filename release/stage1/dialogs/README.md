# Диалоги с ИИ

| Файл | Что это |
|---|---|
| `development-session-export.zip` | Экспорт сессии разработки из приложения Claude (вкладка Code): полный диалог с инструментальными вызовами, диалоги четырёх субагентов предварительной проверки правил и метаданные сессии. Экспорт сделан перед финальной сборкой комплекта, поэтому последние шаги (заполнение отчёта, этот файл, итоговое сообщение) в него не попали. |
| `model-session-acceptance-run.jsonl` | Диалог с локальной моделью в приёмочном прогоне `20261112T013616Z-2bd8b2`: системные правила, запрос оператора, вызовы трёх инструментов и ответы сервера, разбор каждой заявки, записанные черновики. Три сессии подряд. Копия `demo/acceptance/runs/20261112T013616Z-2bd8b2/dialog.jsonl`. |

Диалоги с моделью для остальных прогонов лежат рядом с их артефактами:
`demo/acceptance/eval-runs/…/dialog.jsonl` (набор для оценки) и
`evidence/model-comparison/…/dialog.jsonl` (сравнение моделей и версий правил).

## Что изменено в экспорте сессии

В копии экспорта замаскирован личный адрес электронной почты владельца сессии: он
попал в служебный контекст приложения, а не в переписку. Шесть вхождений заменены на
`<email-hidden>`; больше ничего не менялось. Исходный экспорт остался у владельца.

Строки вида `sk-ant-api03-abcdefgh12345678` в диалоге — заведомо поддельное значение из
тестов маскирования секретов, а не ключ. Настоящих ключей, токенов и паролей в диалоге
нет: модель в рабочем пути локальная и авторизации не требует.

В диалоге и журналах встречается имя пользователя Windows в путях к файлам.
