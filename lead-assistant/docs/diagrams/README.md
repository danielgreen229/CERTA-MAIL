# Диаграммы вариантов использования

UML-диаграммы вариантов использования AI-помощника менеджера по заявкам. Исходники в PlantUML (`*.puml`), рядом лежат готовые SVG с тем же именем.

| Файл | Название | Что показывает |
|---|---|---|
| `01-vhod-i-smena-parolya` | Вход и смена начального пароля | Администратор создаёт пользователя, сотрудник входит и при первом входе обязательно меняет начальный пароль. |
| `02-priyom-pisem` | Приём писем из почтовых ящиков и Telegram-ботов | Фоновый обработчик раз в минуту забирает письма по IMAP и сообщения ботов и импортирует их без дублей. |
| `03-razbor-agentom-mcp` | Автоматический разбор заявок агентом через MCP | Агент через инструменты list_leads, get_lead и update_lead определяет категорию и срочность по цитатам, готовит черновик и сводку. |
| `04-rabota-menedzhera-s-pismom` | Работа менеджера с письмом | Менеджер открывает письмо, принимает, исправляет или отклоняет черновик, назначает ответственного и смотрит историю. |
| `05-otvet-klientu` | Ответ клиенту по почте или в Telegram | Ответ уходит по SMTP с того же ящика или через бота, один раз, а каждая попытка пишется в журнал. |
| `06-podklyucheniya` | Подключения: почтовые ящики, Telegram-боты и сервисы | Сотрудник ведёт свои ящики и ботов, а администратор видит все подключения и настраивает CRM, TMS и тарифы. |
| `07-baza-znaniy` | База знаний | Руководитель загружает документы, менеджеры ищут по ним и видят фрагменты источников в окне письма с учётом роли и срока действия. |
| `08-pochta-papki-i-vygruzka` | Почта: папки, фильтры, поиск и выгрузка | Папки по срочности, «В работе» и «Решённые», фильтры сводки, вкладки категорий, поиск и выгрузка в Excel, PDF, Word и JSON. |
| `09-kachestvo-i-uvedomleniya` | Качество разбора и уведомления | Руководитель смотрит метрики качества и историю разборов, сотрудники получают звук и системные уведомления о новых письмах. |
| `10-administrirovanie` | Администрирование | Иерархия ролей и задачи администратора: сроки и рабочее время, отделы, сотрудники, модель, журнал, резервная копия через leads-backup. |
| `11-rabota-v-ai-kliente` | Работа в AI-клиенте (Claude Code) | Оператор вызывает /process-leads, а модель видит три MCP-инструмента сервера leads и вызывает их. |
| `12-onbording` | Онбординг: обучение при первом входе | При первом входе окно предлагает пошаговый тур, отметка о прохождении хранится в браузере, тур можно пройти заново из настроек. |

## Как пересобрать SVG

```powershell
docker run --rm -v "${PWD}:/data" plantuml/plantuml:1.2024.7 -tsvg -charset UTF-8 "/data/*.puml"
```

Команду запускать из папки `docs/diagrams`. Шрифт DejaVu Sans в образе есть, кириллица отображается без замен.
